# 运行截图清单（在 Ubuntu 22.04.5 里照着敲，每条截一张）

> 用途：作业「③ 提交与答辩」要求交**运行截图**。本文件给出现成的命令、预期画面、以及建议的文件名。
> 全程只需一个终端窗口，命令都在工程根目录（`cd sparseio`）下执行。

建议截图分辨率别太小（终端字号调到 12–14），保证日志文字清晰可读。

## 截图 1 —— 编译通过、零告警

```bash
make clean && make
```

**画面要点**：每个 `.c` 一行 `CC`，最后 `LD sparseio` / `构建完成`，**没有任何 warning**。
**命名**：`screenshots/01_build.png`

## 截图 2 —— 创建空洞文件 + status 显示空洞占比（最关键的一张）

```bash
head -c 4194304 /dev/urandom > /tmp/src.bin
./sparseio create --target=/tmp/dl.bin --size=8M --block=256K --head=64K
./sparseio status --target=/tmp/dl.bin --block=256K --head=64K
```

**画面要点**：
- `稀疏文件已创建`
- `逻辑大小 : 8.00 MiB (8388608 字节)`
- `实际占用 : 0 B (0 字节, 0 个 512B 块)`
- `空洞占比 : 100.00%`

**命名**：`screenshots/02_create_status.png`

---

## 截图 3 —— 用 `ls -ls` / `du` 直接看到空洞

```bash
ls -ls /tmp/dl.bin
du -h /tmp/dl.bin
stat -c '逻辑=%s 占用块数=%b' /tmp/dl.bin
```

**画面要点**：`ls -ls` 第 1 列（占用块数）为 `0`，而大小列显示 `8388608`；`du` 显示 `0`。
**命名**：`screenshots/03_ls_ls_sparse.png`

---

## 截图 4 —— 定点写入 + 主动中断（记录已完成偏移）

```bash
./sparseio write --target=/tmp/dl.bin --source=file:///tmp/src.bin --block=256K --head=64K --limit=5
echo "退出码=$?"
```

**画面要点**：
- 每行 `已完成偏移 [    65536 , + 262144)  块 k/N  xx.xx%`
- 最后 `达到 --limit=5，主动中断以演示断点续传`
- `退出码=130`

**命名**：`screenshots/04_write_interrupt.png`

---

## 截图 5 —— 断点续传（跳过已完成块）

```bash
./sparseio status --target=/tmp/dl.bin --block=256K --head=64K
./sparseio write  --target=/tmp/dl.bin --source=file:///tmp/src.bin --block=256K --head=64K
```

**画面要点**：
- 第一条：`分块进度 : 5 / 32 块 (15.62%)`（数字以实际为准）
- 第二条开头：`检测到已有进度位图：已完成 5/32 块，从断点继续`
- 第二条结尾：`本次新写入 xxxxx 字节，本次跳过（已完成）5 块`

**命名**：`screenshots/05_resume.png`

## 截图 6 —— 校验通过 + 与源 sha256 一致

```bash
./sparseio verify --target=/tmp/dl.bin --source=file:///tmp/src.bin --block=256K --head=64K
sha256sum /tmp/src.bin /tmp/dl.bin
```

**画面要点**：`校验通过：` 段里 `已写块 : 32 / 32 块（逐块与源比对一致）`；两条 sha256 完全相同。
**命名**：`screenshots/06_verify_sha256.png`

## 选做（有加分，能体现工作量）

**A. 完整测试套件汇总**
```bash
make test 2>&1 | tail -30
```
画面要点：`用例通过: NN` / `用例失败: 0` / `ALL TESTS PASSED`。
命名：`screenshots/07_make_test.png`

**B. 真实 HTTP Range（证明走的是 206 而不是整文件下载）**
```bash
cd /tmp && head -c 4194304 /dev/urandom > remote.bin
python3 -m http.server 8097 --bind 127.0.0.1 &
curl -s -o /dev/null -D - -H 'Range: bytes=1000-1999' http://127.0.0.1:8097/remote.bin | head -5
```
画面要点：`HTTP/1.1 206 Partial Content` 与 `Content-Range: bytes 1000-1999/4194304`。
命名：`screenshots/08_http_range.png`

**C. Ctrl-C 真实中断（比 `--limit` 更贴近"断线"）**
```bash
./sparseio write --target=/tmp/dl.bin --source=file:///tmp/src.bin --block=256K --head=64K --delay=200
# 看到几行进度后按 Ctrl-C
echo "退出码=$?"      # 130
```
命名：`screenshots/09_sigint.png`
