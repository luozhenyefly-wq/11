## 五、答辩要能讲清的四件事

1. **空洞怎么来的**：`ftruncate()` 只改 `i_size`，不分配数据块 → `st_size` 与 `st_blocks*512` 的差值就是空洞。
2. **为什么用 `pwrite` 而不是 `lseek`+`write`**：`pwrite` 自带偏移、不动文件偏移量，天然不会串位、不会把空洞写实。
3. **断点续传怎么保证不撒谎**：`写数据 → 回读比对 → fsync → 位图置位 → 写 .tmp → rename`；
   宁可"数据写了但没记账"（重下一次，幂等），也不能"记了账但数据没落盘"（会静默跳过坏数据）。
4. **怎么证明它是对的**：不靠日志，靠 `sha256sum` 外部比对 + 未写区间逐字节为 0 + 退出码契约（2/4/5/130）。
