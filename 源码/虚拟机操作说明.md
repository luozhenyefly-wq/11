# 虚拟机内操作说明（Ubuntu 22.04.5）

> **本文的定位**：只解决"怎么把工程弄进虚拟机"这一件事。命令清单与预期画面见
> `截图清单.md`，编译/退出码/排错见 `编译与运行说明.md`，交件核对见 `提交清单.md`。
> 已经能在虚拟机里直接 `cd` 到工程目录的话，**本文可以跳过**。

这份文件是给你在虚拟机里跑出**真实运行记录**用的，一共 4 步，大约 3 分钟。

---

## 第 0 步：把工程目录放进虚拟机

工程目录就是本目录（`sparseio/`）。两种放法，任选一种：

**方法 A：拖拽（最快）**
1. 在宿主机把这个 `sparseio` 文件夹拖进虚拟机桌面；
2. 在虚拟机里打开「文件」，确认桌面出现 `sparseio` 文件夹。

**方法 B：VMware 共享文件夹**
1. 关闭虚拟机 → VMware 菜单「虚拟机 → 设置 → 选项 → 共享文件夹 → 总是启用」，
   添加宿主机目录，名称填 `share`；
2. 开机后工程出现在 `/mnt/hgfs/share/sparseio`。

---

## 第 1 步：打开终端，进入工程目录

在虚拟机里按 `Ctrl + Alt + T` 打开终端，然后：

```bash
cd ~/Desktop/sparseio        # 方法 A
# cd /mnt/hgfs/share/sparseio   # 方法 B

ls                           # 应该能看到 Makefile README.md src tests report.sh
```

---

## 第 2 步：一键跑完 编译 + 测试 + 演示，并留档

```bash
bash report.sh
```

它做的事情：
1. `make clean && make`（编译，告警一起留档）
2. `make test`（6 组测试用例：空洞 / 定点写入 / 断点续传 / 数据一致性 / 边界 / SIGINT）
3. `make demo`（断点续传演示，含本地 HTTP Range 数据源）
4. 真实 HTTP Range 冒烟测试
5. 全部输出写到 `logs/` 目录

跑完会打印「用例通过 / 用例失败」汇总和证据文件清单。

---

## 第 3 步：手工截几张图（作业要求「板端运行截图」）

在终端里依次执行下面的命令，每条跑完**截一次图**（虚拟机内 `PrtScn` 或宿主机截图工具都行）：

```bash
# ① 编译过程（零告警）
make clean && make

# ② status：空洞占比 —— 这张最关键，能看到「逻辑 8MiB / 实际 0 字节」
cd tests/work/demo 2>/dev/null || cd tests/work
./../../sparseio status --target=dl.bin --block=256K --head=64K

# ③ ls -ls 直接看到稀疏文件（第 1 列是占用块数，未下载部分是 0）
ls -ls dl.bin
du -h dl.bin

# ④ 断点续传：先中断，再续传
./../../sparseio write --target=dl.bin --source=file://$PWD/../../tests/work/demo/server_file.bin --block=256K --head=64K --limit=5
./../../sparseio write --target=dl.bin --source=file://$PWD/../../tests/work/demo/server_file.bin --block=256K --head=64K

# ⑤ 校验通过
./../../sparseio verify --target=dl.bin --source=file://$PWD/../../tests/work/demo/server_file.bin --block=256K --head=64K

# ⑥ 完整测试汇总（最后几行有 ALL TESTS PASSED）
make test
```

> 更简单的做法：先跑 `make demo`，然后照着终端回滚，一条条重新执行并截图。

截图存到 `sparseio/screenshots/` 目录里，命名建议：
`01_build.png`、`02_status_hole.png`、`03_ls_ls_sparse.png`、`04_resume.png`、`05_verify.png`、`06_test_pass.png`

---

## 第 4 步：把结果拿回宿主机

把虚拟机里的 `sparseio` 目录（重点是新增的 `logs/` 和 `screenshots/`）
拷回宿主机桌面即可。我会用这些真实输出把 README 里的结果段落补齐，
最后整理成一份完整交付文件放到桌面。

## 附：如果想自己一步步手工验证（不跑脚本）

```bash
# 造一个 4MiB 的"服务器端"文件
head -c 4194304 /dev/urandom > /tmp/src.bin

# 建 8MiB 空洞文件，检查实际占用为 0
./sparseio create --target=/tmp/dl.bin --size=8M --block=256K
stat -c '逻辑=%s 占用字节=%b*512' /tmp/dl.bin
du -h /tmp/dl.bin

# 只下 5 块就停（模拟中断）
./sparseio write --target=/tmp/dl.bin --source=file:///tmp/src.bin --block=256K --limit=5
echo "中断退出码=$?"

# 看进度和空洞
./sparseio status --target=/tmp/dl.bin --block=256K

# 续传（注意日志里的"跳过"和"新写入"字节数）
./sparseio write --target=/tmp/dl.bin --source=file:///tmp/src.bin --block=256K

# 校验
./sparseio verify --target=/tmp/dl.bin --source=file:///tmp/src.bin --block=256K
sha256sum /tmp/src.bin /tmp/dl.bin
```
